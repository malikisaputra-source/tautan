# AGENTS — Kas Warung
Aplikasi buku kas warung, HTML/CSS/JS murni, data di localStorage (`kasWarung.v1`). Panduan lengkap: `.claude/skills/ubah-kas-warung/SKILL.md`. Sistem desain: `DESIGN.md` (wajib dijaga: token tema, kontras AA, fokus terlihat, target ≥44px, responsif 390px–desktop, reduced-motion).
- `index.html` kerangka & halaman, `style.css` gaya, `app.js` logika, `tema.css`/`tema.js` token customizer.
- Field data baru → `dataKosong()` + migrasi di `muat()`; jangan hapus data pengguna. Tanpa build tool.
