MalikiStudio

Cara pasang semua software Maliki

Cari aplikasimu di tabel, lihat jenis berkasnya (.dmg, .exe, .apk, atau .zip), lalu ikuti langkah bergambar untuk jenis itu. Caranya sama untuk semua aplikasi dengan jenis berkas yang sama.

Kenapa muncul peringatan keamanan? Semua aplikasi ini gratis dan belum memakai sertifikat berbayar dari Apple, Microsoft, atau Google. Peringatan itu wajar dan cukup dilewati sekali sesuai langkah di bawah. Semua berkas resmi hanya diunduh dari github.com/malikisaputra-source/unduh atau tautan di malikisaputra.biz.id.

Mac yang didukung: Apple Silicon (M1–M4), macOS 12+. Windows: 10/11 64-bit. Android: 10+.

Berkas .dmg MacBook

Untuk Studio Maliki, Maliki Agent, dan Edit Maliki. Contoh di bawah memakai Edit Maliki; aplikasi lain caranya sama.

  1. Buka berkas .dmg

    Setelah unduhan selesai, klik dua kali berkas ….dmg di folder Downloads. Tunggu sampai jendelanya terbuka.

    Edit-Maliki-Mac.dmgDownloads

  2. Seret ke Applications

    Tarik ikon aplikasi ke folder Applications di sebelahnya. Kalau ditanya karena sudah ada versi lama, pilih Ganti. Hasil kerjamu tetap aman.

    E
    Edit Maliki
    →
    Applications

  3. Pertama kali: klik kanan → Buka

    Buka folder Applications, klik kanan (atau Control + klik) ikon aplikasi, lalu pilih Buka. Jangan klik dua kali untuk pembukaan pertama.

    BukaTampilkan Isi PaketPindahkan ke Tong SampahDapatkan Info

  4. Tekan Buka sekali lagi

    macOS bertanya karena pengembangnya belum terdaftar di Apple. Tekan Buka. Berikutnya cukup klik dua kali seperti aplikasi biasa.

    Selesai! Aplikasi terbuka di jendelanya sendiri.

    macOS tidak dapat memverifikasi pengembang aplikasi ini. Yakin ingin membukanya?
    BatalBuka
Tidak ada tombol "Buka", hanya "Selesai" atau "Pindahkan ke Tong Sampah"

Tekan Selesai. Buka Pengaturan Sistem → Privasi & Keamanan, gulir ke bawah sampai ada tulisan tentang aplikasi tadi, tekan Tetap Buka, lalu masukkan sandi Mac-mu. Buka aplikasinya lagi.

Muncul "aplikasi rusak dan tidak bisa dibuka"

Biasanya unduhan belum selesai. Hapus berkas .dmg, unduh ulang sampai selesai, lalu ulangi dari langkah 1.

Mac saya Intel

Versi .dmg saat ini hanya untuk Apple Silicon (M1–M4). Cek di menu Apple → Tentang Mac Ini: kalau tertulis "Chip Apple M…", berarti didukung.

Berkas .exe Windows 10/11

Untuk Studio Maliki, Maliki Agent, dan Edit Maliki. Tidak perlu hak admin. Versi baru nanti cukup jalankan installer barunya; hasil kerjamu tidak terhapus.

  1. Jalankan installer

    Klik dua kali berkas ….exe di folder Unduhan.

    Edit-Maliki-Windows.exeUnduhan

  2. Layar biru "Windows melindungi PC Anda"

    Klik tulisan Info selengkapnya, lalu tekan tombol Tetap jalankan yang muncul.

    Windows melindungi PC AndaSmartScreen mencegah aplikasi tak dikenal dimulai.Info selengkapnya
    Tetap jalankanJangan jalankan

  3. Ikuti wizard

    Pilih Saya setuju pada lisensi → Berikutnya. Centang Buat pintasan di Desktop kalau mau, lalu Pasang.

    Pasang aplikasi☑ Buat pintasan di Desktop
    KembaliPasang

  4. Selesai, lalu buka

    Biarkan centang Buka … sekarang, tekan Selesai. Lain kali buka dari pintasan Desktop atau menu Start.

    Selesai! Aplikasi terbuka di jendelanya sendiri.

    Pemasangan selesai☑ Buka aplikasi sekarang
    Selesai
Tidak ada tombol "Tetap jalankan"

Klik tulisan Info selengkapnya dulu; tombolnya baru muncul setelah itu. Kalau antivirus lain memblokir, izinkan berkas ini.

Jendela aplikasi kosong putih

Aplikasi memakai Microsoft Edge WebView2 bawaan Windows 10/11. Jalankan Windows Update, lalu buka lagi.

Berkas .apk Android 10+

Untuk Klip HP (Studio Maliki), Maliki Agent, Maliki Web, Maliki Konten Suara, dan Edit Maliki. Dipasang dari berkas, bukan dari Play Store.

  1. Unduh berkas .apk di HP

    Unduh dari HP. Kalau browser bilang "berkas ini bisa membahayakan", pilih Tetap unduh.

    ….apkUnduhan
    Tetap unduh

  2. Buka berkasnya

    Ketuk notifikasi unduhan, atau buka aplikasi File → Download, lalu ketuk berkas .apk.

    Download📄 ….apkvideo-saya.mp4

  3. Izinkan pemasangan dari sumber ini

    Kalau muncul "tidak diizinkan memasang aplikasi dari sumber ini", ketuk Setelan, nyalakan Izinkan dari sumber ini, lalu tekan tombol kembali.

    Instal aplikasi tak dikenal
    Izinkan dari sumber ini

    Ketuk Instal. Kalau muncul Play Protect, ketuk Pindai aplikasi; setelah dinyatakan aman, ketuk Instal, lalu Buka.

    Selesai! Ikon aplikasi muncul di layar HP.

Berkas .zip Mac & Windows

Untuk Maliki Web dan Maliki Konten Suara. Satu .zip untuk Mac dan Windows. Butuh internet saat pertama memasang (sekitar 1–3 menit).

  1. Ekstrak .zip

    Mac: klik dua kali berkas .zip. Windows: klik kanan → Ekstrak Semua → Ekstrak. Jangan menjalankan dari dalam .zip tanpa diekstrak.

    Maliki-Web-0.1.zip→📁 Maliki-Web-0.1

  2. Jalankan pemasang

    Di folder hasil ekstrak: Mac klik kanan berkas Pasang ….command → Buka → Buka. Windows klik dua kali Pasang … (Windows).bat; kalau muncul layar biru, Info selengkapnya → Tetap jalankan.

    BukaBuka DenganDapatkan Info

  3. Tunggu jendela hitam selesai

    Jendela Terminal/Command Prompt akan menampilkan proses pemasangan. Jangan ditutup sampai muncul tulisan selesai.

    • Memasang uv…
    • Menyiapkan aplikasi…
    ✅ Selesai! Buka dari Desktop.

  4. Buka dari Desktop

    Pintasan aplikasi muncul di Desktop (Mac juga di folder Applications, Windows juga di menu Start). Klik untuk membuka.

    Selesai! Pindahkan folder hasil ekstrak? Jalankan pemasangnya sekali lagi.

    Maliki Web
Mac: "tidak dapat dibuka karena dari pengembang tak dikenal"

Pastikan membuka dengan klik kanan → Buka, bukan klik dua kali. Kalau tetap ditolak: Pengaturan Sistem → Privasi & Keamanan → Tetap Buka.

Jendela hitam langsung tertutup atau ada tulisan merah

Cek koneksi internet lalu jalankan pemasangnya lagi. Kalau masih gagal, kirim screenshot jendelanya di #lapor-bug Discord.

Catatan khusus tiap aplikasi

Setelah terpasang, beberapa aplikasi butuh satu langkah tambahan saat pertama dipakai.

Studio Maliki · Klip HP

  • Pertama kali membuat klip, model suara Whisper (±500 MB) diunduh sekali.
  • Pernah memasang Klip HP 2.0/2.1? Hapus aplikasi lamanya sekali, lalu pasang yang baru. Pembaruan berikutnya bisa langsung menimpa.

Maliki Agent

  • Buka Pengaturan → tempel kunci Gemini gratis dari aistudio.google.com/apikey → Simpan → Uji AI.
  • HP: izinkan notifikasi; kalau tim berhenti di tengah jalan, atur baterai Maliki Agent ke Tidak dibatasi.
  • Laptop juga bisa memakai Ollama atau langganan Claude/ChatGPT.

Maliki Web & Konten Suara

  • Isi AI milikmu di Pengaturan: Gemini (gratis), Ollama, atau langganan lewat Claude Code/Codex/OpenCode.
  • Konten Suara: suara bawaan perangkat langsung jalan; suara AI lokal (VoxCPM2) opsional di laptop.

Edit Maliki

  • Pertama kali mengedit, model transkrip diunduh sekali (±500 MB laptop, ±60 MB HP).
  • Di HP, transkrip lebih lambat; mulai dengan video 15–60 detik dan biarkan aplikasi terbuka.
  • Judul AI dan "Revisi pakai kalimat" (laptop) butuh kunci Gemini gratis di Pengaturan AI.
