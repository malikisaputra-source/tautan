# Panduan Pemakaian — Keuangan Pribadi & Bendahara

Santai aja, ini dibuat untuk yang belum pernah pakai aplikasi keuangan sama sekali. Baca pelan-pelan, praktikkan sambil buka aplikasinya.

## 1. Pasang / buka aplikasinya
Aplikasi ini cuma satu folder berisi file web. Tidak perlu install apa-apa, tidak perlu internet (kecuali untuk huruf/font).

**Di laptop**
1. Unduh ZIP-nya, klik kanan › **Extract All / Ekstrak**.
2. Buka folder hasil ekstrak, klik dua kali **`index.html`**. Aplikasi terbuka di browser.
3. Biar gampang dibuka lagi, tekan **Ctrl+D** (Mac: Cmd+D) untuk menyimpan sebagai bookmark.

**Di HP**
- Cara paling enak: minta teman/kamu sendiri mengunggah folder ini ke Netlify (seret folder ke app.netlify.com/drop) atau GitHub Pages, lalu buka link-nya di Chrome HP.
- Setelah terbuka, ketuk menu titik tiga Chrome › **Tambahkan ke layar utama**. Sekarang ada ikonnya seperti aplikasi biasa.

> Penting: data tersimpan **di browser itu saja**. Buka di HP lain atau browser lain = data kosong. Untuk pindah, pakai fitur Cadangan (bagian 5).

## 2. Pilih mode
Saat pertama dibuka muncul pertanyaan **"Mau dipakai untuk apa?"**
- **Keuangan Pribadi** — untuk uang kamu sendiri.
- **Bendahara** — untuk kas masjid, RT/RW, arisan, komunitas, kelas.

Bingung? Pilih saja salah satu. Ganti kapan pun lewat tombol **Ganti mode** (sidebar laptop) atau menu **Atur › Mode aplikasi**. Data dua mode disimpan terpisah, jadi tidak tercampur dan tidak hilang.

Awalnya aplikasi berisi **data contoh** supaya kamu bisa lihat hasilnya. Kalau sudah paham, kosongkan dulu (lihat 3f / 4f).

## 3. Mode Pribadi, langkah demi langkah

### a. Mencatat transaksi
1. Tekan tombol **+** (bulat hijau limau di kanan bawah HP) atau **Catat transaksi** (laptop).
2. Pilih **Pengeluaran** atau **Pemasukan** di atas.
3. Ketik jumlahnya. Bisa juga tekan tombol cepat **+10rb, +25rb, +50rb, +100rb** (bisa ditekan berkali-kali).
4. Pilih kategori (Makan & Minum, Transportasi, dll).
5. Pilih dompetnya (Tunai, Bank, E-wallet) dan tanggal. Catatan boleh dikosongkan.
6. Tekan **Simpan**. Selesai, saldo langsung berubah.

Salah catat? Ketuk transaksinya › ubah › **Simpan**, atau tekan **Hapus**. Habis menghapus muncul tombol **Urungkan** beberapa detik kalau kepencet.

### b. Dompet & pindah saldo
- Di **Beranda** terlihat saldo tiap dompet. Total saldo ada di kartu hijau besar.
- Atur saldo awal: **Atur › Dompet** › ketuk dompet › isi **Saldo awal** (uang yang ada sekarang).
- Tambah dompet (mis. "Mandiri", "OVO", "Celengan"): **Atur › Tambah dompet**.
- Tarik tunai di ATM atau isi saldo e-wallet? Pakai **Pindah saldo**. Ini tidak dihitung sebagai pengeluaran, cuma memindah uang.

### c. Anggaran (batas belanja)
1. Buka menu **Anggaran**.
2. Ketuk kartu kategori, isi batas per bulan (mis. Makan Rp1.800.000), **Simpan**.
3. Cincin akan terisi sesuai pemakaian: label **Aman**, **Hampir habis** (di atas 85%), atau **Lewat** (merah).
4. Tombol panah di kanan atas untuk melihat bulan lain.

### d. Target tabungan
1. Menu **Tabungan** › **Target baru**. Isi nama (mis. "Dana darurat"), nominal target, dan yang sudah terkumpul.
2. Tiap kali menabung, tekan **Setor** di kartunya.
3. Ubah atau hapus lewat tombol titik tiga di kartu.

### e. Laporan
Menu **Laporan** menampilkan grafik pemasukan vs pengeluaran 6 bulan, donat "ke mana uangmu pergi", dan rasio tabungan (sisa pemasukan). Targetkan minimal 20% ya.
Butuh datanya di Excel? Menu **Transaksi** › **CSV**.

### f. Kategori & mulai dari nol
- Tambah/ubah kategori, ikon, dan warnanya di **Atur › Kategori**.
- Hapus data contoh: **Atur › Kosongkan data mode ini**, ketik **HAPUS**, lalu tekan Kosongkan.

## 4. Mode Bendahara, langkah demi langkah

### a. Isi identitas dulu
1. Buka **Atur**.
2. Isi **nama organisasi**, alamat, kota, **nama bendahara**, **nama ketua**.
3. Isi **saldo awal** (uang kas saat mulai pakai aplikasi) dan **per tanggal** berapa.
4. Tekan **Simpan identitas**. Semua ini muncul di kop dan tanda tangan laporan.

### b. Mengatur pos
Pos = kelompok uang masuk/keluar, mis. *Infak Jumat*, *Iuran Sampah*, *Listrik & Air*, *Honor Marbot*.
Tambah di **Atur › Tambah pos** atau menu **Rekap Pos › Pos baru**. Pilih jenisnya (pemasukan/pengeluaran) dan ikon.

### c. Mencatat kas
1. Tekan **+** / **Catat kas**.
2. Pilih Pemasukan/Pengeluaran, isi jumlah dan **uraian** (wajib, mis. "Infak Jumat pekan 2").
3. Pilih pos dan tanggal.
4. **No. bukti** terisi otomatis: BKM-xx untuk kas masuk, BKK-xx untuk kas keluar. Tulis nomor yang sama di nota/kuitansi aslinya lalu simpan notanya di map. Ini yang bikin laporan kamu bisa dipertanggungjawabkan.
5. **Simpan**. Entri masuk ke **Buku Kas** dengan nomor urut dan saldo berjalan.

Ketuk baris di buku kas untuk mengubah/menghapus.

### d. Membuat laporan & cetak PDF
1. Menu **Laporan**.
2. Pilih periode: **Bulan ini**, **Bulan lalu**, **Tahun ini**, atau isi tanggal Dari–Sampai sendiri.
3. Cek pratinjau kertas: kop, ringkasan saldo, rekap per pos, rincian, tanda tangan.
4. Tekan **Cetak / PDF**. Di jendela cetak:
   - Mau kertas: pilih printer.
   - Mau PDF (untuk dikirim ke grup WA): pilih **Simpan sebagai PDF / Save as PDF**.
   - Di HP Android: Chrome › Bagikan › Cetak › Simpan sebagai PDF.
5. Tanda tangani hasil cetaknya, beres.

### e. Rekap per pos & CSV
- **Rekap Pos** menunjukkan total tiap pos untuk periode yang dipilih di halaman Laporan.
- **Ekspor CSV** (di Buku Kas atau Laporan) bisa dibuka di Excel atau diimpor ke Google Sheets (File › Import).

### f. Mulai dari nol
**Atur › Kosongkan data mode ini** › ketik **HAPUS**. Pos tetap ada, entri kas & saldo awal dikosongkan.

## 5. Backup & pindah HP
Lakukan ini **seminggu sekali** atau sebelum ganti HP / bersih-bersih browser.
1. **Atur › Unduh cadangan (.json)**. Terunduh satu file, mis. `cadangan-keuangan-2026-11-08.json`.
2. Simpan file itu di tempat aman: Google Drive, atau kirim ke WhatsApp diri sendiri.
3. Di HP/laptop baru: buka aplikasinya › **Atur › Pulihkan** › pilih file tadi › **Ganti data**.
Semua data (Pribadi dan Bendahara) ikut pindah.

## 6. FAQ singkat
**Datanya disimpan di mana? Aman?**
Di browser perangkatmu sendiri (localStorage). Tidak dikirim ke server mana pun. Karena itu, rajin backup.

**Kok datanya hilang?**
Biasanya karena buka di browser lain, mode penyamaran (incognito), atau riwayat/data situs dihapus. Pulihkan dari file cadangan.

**Bisa dipakai bareng pengurus lain?**
Belum bisa langsung barengan. Caranya: satu orang (bendahara) yang mencatat, lalu bagikan PDF laporan atau file cadangan ke pengurus lain.

**Bisa offline?**
Bisa. Tanpa internet hanya huruf yang berganti ke huruf bawaan HP.

**Uang pindah dari bank ke e-wallet kok jadi pengeluaran?**
Jangan dicatat sebagai pengeluaran. Pakai **Pindah saldo**.

**Angka saldo bendahara tidak cocok dengan uang di kotak?**
Cek saldo awal di Atur, lalu cocokkan buku kas baris per baris dengan nota. Bisa juga cari pakai kolom pencarian (uraian atau no. bukti).

**Mau ganti warna atau nama aplikasi?**
Lihat bagian "Ubah brand & warna" di README.md, atau minta bantuan Claude (skill sudah disertakan).

## Ganti logo & foto

Pengaturan gambar ada di satu tempat: objek `GAMBAR` di awal `app.js` (`maks: 400` px, ikon bawaan sidebar & kop). Gambar diunggah dari aplikasi, diperkecil otomatis, lalu disimpan sebagai dataURL di browser (ikut **Unduh cadangan .json**).

| Slot | Cara mengganti | Rasio | Bila kosong |
|---|---|---|---|
| Logo organisasi di kop **Laporan kas** (cetak/PDF) & sidebar Mode Bendahara | **Atur › Identitas organisasi › Pilih gambar** | 1:1 | ikon masjid; gagal dimuat = inisial organisasi |
| Foto profil / avatar di sidebar Mode Pribadi | **Atur › Profil › Pilih gambar** (+ nama panggilan) | 1:1 | ikon dompet; gagal dimuat = inisial |
| Favicon aplikasi | timpa `ikon.svg` | 1:1 | – |

Tombol **Hapus** di sebelah pratinjau mengembalikan ikon bawaan. Pakai logo latar putih/transparan agar kop laporan rapi saat dicetak.

## Ubah sendiri sesuai kebutuhanmu pakai AI

Kamu tidak perlu jago coding. Template ini sudah disiapkan supaya mudah diubah AI: ada **AGENTS.md** (aturan proyek untuk AI), **DESIGN.md** (gaya desain), dan skill Claude di folder `.claude/skills/`. Pilih salah satu cara di bawah.

### Cara 1: ChatGPT, Claude, atau Gemini di browser (paling gampang, gratis)
1. Unduh ZIP template ini, lalu ekstrak.
2. Buka chatgpt.com, claude.ai, atau gemini.google.com.
3. Unggah berkas yang mau diubah (biasanya `index.html`, `style.css`, `app.js`, atau berkas data). Unggah juga `AGENTS.md` dan `DESIGN.md` (kalau ada) biar AI paham aturannya. ChatGPT juga bisa menerima ZIP utuh.
4. Tulis permintaanmu (contoh di bawah), lalu minta: "Kirim ulang berkas yang diubah secara utuh."
5. Ganti berkas lama dengan hasil dari AI, lalu buka `index.html` di browser untuk cek.

### Cara 2: Claude Code (paling rapi untuk perubahan besar)
1. Pasang Claude Code (lihat claude.com/claude-code), atau pakai aplikasi Claude Desktop tab Code.
2. Buka folder template ini, lalu jalankan `claude` di terminal folder itu.
3. Tulis permintaanmu. Kalau ada folder `.claude/skills/ubah-…`, Claude Code otomatis memakainya, jadi hasilnya tetap mengikuti desain aslinya.

### Cara 3: Codex (OpenAI)
1. Pasang Codex CLI atau pakai Codex di aplikasi ChatGPT.
2. Buka folder template, jalankan `codex`. Codex otomatis membaca `AGENTS.md`.
3. Tulis permintaanmu, cek perubahannya, lalu setujui.

### Cara 4: Google Antigravity atau Gemini CLI (gratis)
1. Antigravity: buka aplikasinya, pilih **Open Folder** ke folder template ini, lalu tulis permintaan di panel agen.
2. Gemini CLI: jalankan `gemini` di folder template.
3. Di awal, tulis: "Baca AGENTS.md dan DESIGN.md dulu sebelum mengubah apa pun."

### Contoh permintaan yang bisa langsung kamu pakai
- "Ganti nama, logo teks, dan warna utama jadi hijau tua sesuai usahaku: [nama usaha]."
- "Tambahkan kolom [nama kolom] di formulir dan tampilkan di daftar."
- "Ubah semua data contoh jadi data usahaku: [tempel datanya]."
- "Tambahkan halaman/menu baru untuk [kebutuhan], gaya desainnya sama dengan yang sudah ada."
- "Jelaskan dulu cara kerja aplikasi ini dengan bahasa sederhana, baru ubah [bagian]."

### Tips biar hasilnya bagus
- Satu permintaan = satu perubahan. Cek dulu hasilnya, baru minta yang berikutnya.
- Simpan salinan folder asli sebelum mengubah, jadi bisa balik kalau ada yang rusak.
- Kalau ada error, salin pesan errornya (klik kanan > Inspect > Console) lalu tempel ke AI.
- Data aplikasi tersimpan di browser (localStorage). Backup dulu sebelum ganti versi.
