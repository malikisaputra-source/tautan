Direktori Lembah SariRumah ibadah semua umat

Semua rumah ibadah, satu peta

Masjid, musala, gereja, pura, vihara, dan klenteng di Kota Lembah Sari. Data diisi dan diperbarui oleh warga, dicek pengurus.

    Peta belum bisa dimuatPeriksa koneksi internet. Daftar tetap bisa dipakai.

    Ajukan tempat baru

    Tambahkan rumah ibadah yang belum ada. Pengurus akan mengecek sebelum tampil di direktori.

    Masuk dulu sebagai member

    Cukup nama dan PIN 4–6 angka. Supaya pengurus tahu siapa yang mengusulkan.

    Jenis rumah ibadah
    Titik lokasi ketuk peta kecil untuk memindahkan pin
    Fasilitas
    Foto opsional, diperkecil otomatis

    Antrean moderasi

    Setiap usulan dicek pengurus sebelum tampil. Semua keputusan tercatat di riwayat.

    Khusus pengurus

    Masuk dengan akun pengurus untuk menyetujui atau menolak usulan. Di data contoh: Pengurus Kota, PIN 1234.

      Data & akun

      Data tersimpan di perangkat ini (localStorage). Ekspor rutin, atau sambungkan ke Google Sheets/Supabase supaya banyak member bisa mengisi bersama.

      Ekspor

      JSON untuk cadangan lengkap (termasuk antrean & riwayat). CSV untuk dibuka di Excel/Google Sheets.

      Impor

      JSON cadangan menggantikan semua data. CSV menambah/memperbarui tempat berdasarkan kolom id.

      Akun member

        PIN hanya penanda sederhana di perangkat ini, bukan sistem keamanan. Untuk banyak member sungguhan, baca README bagian "Banyak member".

        Mulai ulang

        Kembalikan data contoh, atau kosongkan semua tempat untuk mulai mengisi kotamu sendiri.
