Cara pakai & aman

01Apa itu skill?

Folder berisi SKILL.md (instruksi) dan kadang skrip. Agen AI membacanya otomatis saat tugasnya cocok, jadi kamu tidak perlu menulis prompt panjang tiap kali.

02Cara pasang

Buka terminal di folder proyekmu, tempel perintah npx skills add …, pilih agen (Claude Code, Codex, Gemini CLI, Cursor). Butuh Node.js. Skill masuk ke .claude/skills/.

03Cek sebelum pasang

Skill berjalan dengan izin penuh agen. Pilih label Resmi atau yang teruji, baca SKILL.md dan folder scripts/, dan waspadai repo tiruan bernama mirip.

04Jangan pasang semua

Terlalu banyak skill bikin agen bingung dan boros token. Pasang 2–3 yang kamu butuh, pakai di proyek nyata minggu ini, baru tambah lagi.
